2. js/data.js - DATA YANG BISA DIEDIT
=====================================

WA
    Nomor WhatsApp tujuan semua tombol chat. Tulis dengan format internasional
    tanpa tanda +, contoh 6281234567890. Jika dikosongkan, WhatsApp akan
    meminta pengunjung memilih kontak sendiri.

D
    Daftar paket (Basic, Business, Professional). Setiap paket berisi:

    c       kode paket, contoh WB-01
    n       nama paket
    tag     keterangan singkat di bawah nama
    r       jatah revisi
    lo      harga terendah dalam rupiah (untuk hitung estimasi)
    hi      harga tertinggi dalam rupiah (untuk hitung estimasi)
    p       teks harga yang tampil di halaman
    s       daftar lingkup kerja (daftar centang)
    o       hasil akhir yang diterima
    src     1 = tampilkan lencana "Source code termasuk", 0 = sembunyikan

    Catatan: jika harga diubah, ubah juga p (teks) dan lo / hi (angka)
    agar estimasi tetap sesuai.


3. js/main.js - FUNGSI JAVASCRIPT
=================================

$(s)
    Singkatan dari document.querySelector. Dipakai untuk mengambil elemen
    halaman, contoh $("#g").

sel
    Kumpulan kode paket yang sedang dipilih untuk estimasi (bukan fungsi,
    tetapi dipakai oleh fungsi-fungsi lain).

fmt(n)
    Mengubah angka rupiah menjadi teks singkat. Contoh: 500000 menjadi "500
    rb", 1500000 menjadi "1,5 jt".

wa(t)
    Membuat link WhatsApp (wa.me) yang berisi nomor WA dan pesan t yang sudah
    di-encode.

ic
    Konstanta berisi ikon chat (SVG) untuk tombol tanya via WhatsApp di kartu.

chip(d)
    Mengembalikan lencana "Source code termasuk" jika paket d memiliki src =
    1; jika tidak, mengembalikan teks kosong.

card(d)
    Membuat HTML satu kartu paket untuk tampilan Grid: kode, nama, keterangan,
    harga, revisi, daftar lingkup kerja, akordeon "Hasil akhir yang diterima",
    tombol "Tambah ke estimasi", dan tombol chat WhatsApp.

row(d)
    Membuat HTML satu baris untuk tampilan Tabel: Kode, Layanan, Lingkup
    kerja, Hasil akhir, Revisi, Harga, dan tombol "+" untuk estimasi.

Render awal (jalan sekali saat halaman dibuka)
    Mengisi #g (kartu) dan #tb (baris tabel) dari data D, lalu memasang link
    WhatsApp konsultasi gratis ke tombol #wa0 (navbar), #wa1 (hero), dan #wa2
    (banner bawah).

upd()
    Menyegarkan tampilan sesuai paket yang dipilih: (1) mengubah teks tombol
    estimasi di kartu dan tabel menjadi "Ditambahkan" atau "Tambah ke
    estimasi"; (2) menghitung total harga terendah dan tertinggi dari paket
    terpilih; (3) menampilkan atau menyembunyikan bar estimasi #est; (4)
    mengisi jumlah paket (#cnt), total (#tot), dan link WhatsApp pada tombol
    #send.

Event klik (satu listener untuk seluruh halaman)
    Menangani tiga jenis klik: (1) tombol ber-atribut data-c menambah atau
    menghapus paket dari pilihan lalu memanggil upd(); (2) tombol ber-atribut
    data-v berpindah antara tampilan Grid (#g) dan Tabel (#t) serta menandai
    tombol yang aktif; (3) tombol #clr ("Kosongkan") menghapus semua pilihan
    lalu memanggil upd().

upd() di baris terakhir
    Dipanggil sekali di akhir file agar bar estimasi mulai dalam keadaan benar
    (tersembunyi).


4. index.html - BAGIAN HALAMAN
==============================

  head                Judul halaman, pengaturan layar HP (viewport), font
                      Google (Plus Jakarta Sans dan Instrument Serif), dan
                      link ke css/theme.css serta css/style.css.
  nav                 Navbar yang menempel di atas: logo, link "Paket harga"
                      dan "Konsultasi", serta tombol WhatsApp #wa0.
  header.hero         Bagian pembuka: lencana, judul "Konsultasi gratis
                      bersama kami.", paragraf pengantar, tiga tombol (#wa1,
                      "Lihat paket harga", "Hitung estimasi proyek"), dan dua angka ringkas.
  aside.panel         Kartu di sisi kanan hero: rentang harga tiga paket.
  main#paket          Daftar harga: judul, jumlah layanan, tombol Grid /
                      Tabel, grid kartu (#g), dan tabel (#t dengan isi di
                      #tb).
  section#konsultasi  Banner ajakan konsultasi gratis (#wa2) dan teks footer.
  #est                Bar estimasi yang muncul di bawah layar: jumlah paket
                      (#cnt), total (#tot), tombol "Kosongkan" (#clr), dan
                      "Kirim ke WhatsApp" (#send).
  script              Memuat js/data.js lebih dulu, baru js/main.js. Urutan
                      ini harus dipertahankan.

6. css/style.css - FUNGSI BAGIAN KODE
=====================================

  :root                   pengaturan dasar dan ruang aman layar HP (poni /
                          bilah sistem)
  *                       reset margin dan model ukuran kotak
  html                    scroll halus; jarak atas agar tujuan link tidak
                          tertutup navbar
  body                    warna latar, warna teks, dan font dasar
  body::before            menutup area aman atas di HP agar navbar tidak
                          tembus
  [hidden]                memastikan elemen yang disembunyikan benar-benar
                          hilang
  .wrap                   wadah tengah dengan lebar maksimal 1120px
  .mu, .serif             teks redup, dan font serif (harga, total estimasi)
  nav, .brand, .nl        navbar menempel di atas, logo, dan link navigasi
  .btn                    dasar semua tombol. Varian: .p biru penuh, .on
                          terpilih, .sm kecil, .sq kotak "+" di tabel, .ic
                          tombol ikon chat
  .hero                   bagian pembuka dua kolom; ::before menggambar garis
                          kotak-kotak yang memudar ke tepi
  .pill                   lencana kecil di atas judul
  h1, h1 em               judul besar dan kata miring biru ber-font serif
  .lead, .cta, .stats     paragraf pengantar, deretan tombol hero, dan dua angka ringkas
  .panel, .row            kartu kanan hero dan baris harga (.v = harga)
  .sec, .head, .tools     jarak bagian daftar harga, baris judul, dan area
                          jumlah layanan + tombol tampilan
  .seg                    tombol pilihan Grid / Tabel; [aria-pressed=true]
                          menandai yang aktif
  .grid                   tampilan kartu: 3 kolom, menjadi 2 dan 1 kolom di
                          layar kecil
  .card                   satu kartu paket. Isi: .top (baris kode), .code
                          (lencana kode), .tg (keterangan), .price (harga),
                          .meta (revisi), .chip (lencana source code), .ck
                          (daftar centang), .act (baris tombol)
  details, summary        akordeon "Hasil akhir yang diterima"
  .tw, table, th, td      tampilan tabel; .tw membuat tabel bisa digeser ke
                          samping di layar kecil
  .nw, .tr                teks tidak turun baris, dan rata kanan
  .cta2, .foot            banner ajakan konsultasi dan teks footer
  #est, #est.show         bar estimasi tetap di bawah layar; .show membuatnya
                          meluncur naik
  @media 960px            layar menengah: hero menjadi satu kolom, grid
                          menjadi dua kolom
  @media 620px            layar HP: grid satu kolom, link teks di navbar
                          disembunyikan
  @media reduced-motion   mematikan animasi bagi pengguna yang memilih gerakan
                          minimal
